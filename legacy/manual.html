SAHA Pro v1.4 Operations Guide
Structured User, Partner, & Control Terminal Manual

📱 Customer (User) Mobile Guide Customer

Follow these steps to sign in, purchase Kirana goods from different shops, book service technicians, and authenticate fulfillment using secure OTP codes.

1. User Account Registration & Session

  • Navigate to the **Account** tab in the footer of the Mobile Simulator (left pane).
  • To use the seeded customer profile, enter username customer and password 123, then click **Sign In**.
  • This issues a stateless JWT token signature in the header configuration to authorize booking API requests securely.

2. Hyperlocal Service Dispatch bookings

  • Select **Book Services** from the mobile home dashboard view.
  • Choose a specialty tier (e.g. *Plumber, AC Technician, Electrician*).
  • Click **Book Now**. The system automatically computes a strict 15km geofence map checking, filters out unavailable workers, ranks local candidates by referrals, and pages the top partner.

3. Shop Kirana Essentials

  • Click the **Shop** navigation button in the footer.
  • Toggle the dropdown labeled **Select Hyperlocal Shop** to view different catalog items:
    • *Sai Kirana Store* (located in Madhapur sector, 2.1km range)
    • *Ravi Mart* (located in Ameerpet sector, 4.3km range)
  • Select item category filters or type queries in the search box.
  • Click **Add to Cart**. A slide-up bottom cart menu will display the items count and discounted total.
  • Click **View Cart →** and choose **Confirm Purchase** to execute order checkout.

4. Fulfillment Tracking & Verification

  • Go to the **Status** page in the footer tabs to track orders.
  • Once the assigned worker arrives, share the 4-digit **Secure OTP** displayed inside the order status card. Sharing this code is required for the worker to complete the job and receive payouts.

🔧 Local Partner Operational Guide Worker

Follow these instructions to toggle availability presence, adjust custom price bounds, and claim contract paging alerts.

1. Worker Account Profiles

  • Authenticate by choosing a seeded user profile in the **Account** tab:
    • **Amit Verma (Plumber):** amit / 123 (Jubilee Hills)
    • **Raju Plumber:** raju / 123 (Jubilee Hills)
    • **Kumar Iron Works:** ironpro / 123 (Jubilee Hills)
    • **Sai Kirana Store:** sai / 123 (Madhapur)

2. Presence Toggling

  • Use the active slider switch in your mobile dashboard or inside the Command Center registry to go **Online** or **Offline**.
  • If marked offline or busy, the geofenced dispatcher blocks incoming notifications automatically, avoiding parallel contract alerts.

3. Custom Pricing Console

  • Workers can edit their custom hourly rate under the **Earn** page.
  • **Pricing Freezes:** When the platform administrator fixes pricing for a service category, the pricing input console changes to disabled: `🔒 Editing disabled. Absolute admin price cap enforced.` Transactions use the fixed admin rate.

4. Alert Pages & Payout Completion

  • When paged for a nearby order, a red blinking **Live Dispatch Alert** banner appears.
  • Click **Accept Assignment** to claim the job within the 15-second lockout delay window.
  • Once arrived at the customer, request the customer's 4-digit OTP, enter it in the text box, and select **Complete** to release escrow payouts.

👑 Control Terminal Administrator Guide Admin

Instructions for configuring policy variables, price locks overrides, running diagnostics checks, and monitoring transaction logs.

1. Autopilot & Speed Controls

  • Toggle **Auto-Simulation Mode** to drive traffic generators, auto-claim alerts, and complete state transitions automatically.
  • Set **Sim Speed** multiplier parameters to fast-forward order cycles (`1x` normal up to `10x` hyper).

2. Absolute Price override Controls

  • Locate the **Global Administrative Price Fix Controller** on the dashboard.
  • Type the absolute fixed value for any category and click **Fix**. This locks the rate globally and disables provider rate edits.
  • Click **Release Absolute Admin Locks** to restore custom worker pricing.

3. Proximity Map Grid Monitor

  • The **Regional Service Matrix Map** displays available providers (green), busy providers (yellow), and active orders (red) in Hyderabad sectors.
  • Sectors with pending paged orders flash red.

4. Diagnostics suite & 3,000 Runs stress-Test

  • Click **Launch Diagnostic Suite Verification Matrix** to verify proximity ranges, referral ranking priorities, and price override parameters.
  • **3,000 Synchronous Order Stress Test:** Automatically creates and settles 1,000 services, 1,000 grocery, and 1,000 ironing orders in a synchronous loop. Confirms that final wallet payouts, platform net shares, and tax payouts sum up correctly, validating database stability under heavy load.
