# Languages — what is translated, what is not, and what a person must check

SAAHAA is built for Hyderabad. A professional's public page defaults their
languages to **Telugu, Hindi**. Until 8.7.0 every word of the app was English,
and the gate to earning was a five-question English trade test with three
attempts and a twenty-four hour lock after the third. That is a reading test
wearing a trade test's clothes, and it cost a competent plumber a working day.

This file says exactly how far the fix goes, because the honest failure mode of
translation work is implying more coverage than exists.

---

## The mechanism

`src/ui/i18n.js`. One table per language, `t('key')` in the views, `{name}`
interpolation. Language comes from `?lang=te`, then the saved choice, then the
browser's own preference, then English. `docs` and the legal pages are English.

- **A missing key falls back to English**, never to a blank or a key name. A
  half-drawn screen is worse than an English one, and `core/selftests.i18n.js`
  fails the build if a critical key is missing in any offered language.
- **Adding a language is one object** in that file plus a row in `LANGS`.
- **No view may hardcode a translated string.** If a screen needs new words,
  they go in the table with an English source.

## What is translated (8.7.0)

| Surface | Why it was chosen first |
|---|---|
| The code at the door, both sides | The one moment where a misunderstanding ends a job on a doorstep |
| The stake warning beside the code field | It moves the pro's own money |
| The seven onboarding steps, titles and one-liners | The ladder a pro has to climb before earning anything |
| "SAAHAA never sends codes" | The anti-phishing promise is worthless in a language you cannot read |
| The pro's permanent code, and what it is for | Learned once, used for ever |
| The quiz warning — three wrong tries costs a day | The single most expensive sentence to misread |
| Money words: available, locked, pending, withdraw, minimum | Checked daily |
| The five navigation tabs | You cannot use what you cannot find |
| "This device is full — your changes were not saved" | Silent data loss must not be silent in any language |

## What is NOT translated, and why

- **The 85 per-trade quiz questions** in `domain/quiz.js`. They fall back to
  English, and the quiz screen says so in the reader's own language: *this is a
  test of the trade, not of English — ask someone to read it with you.* A wrong
  translation in a test that can take away a day's work is worse than English.
  Translating these is the next piece of work and it needs a tradesperson, not
  a translator.
- The legal pages, the admin console, and the shop catalogue. The owner reads
  the first two; the third is product names.
- Most of the browsing surface (home, shops, order history). Legible enough
  with the tabs translated, and lower stakes than the list above.

## What a native speaker must do before launch

**Nobody whose first language this is has read these strings.** They were
written to be plain and correct, and that is not the same thing. Until this
review happens the language picker carries a note saying so, in that language —
the app must not imply a review it has not had.

- [ ] A Telugu speaker reads every `te` string aloud, especially the door screen
      and the stake sentence. Money and time words matter more than tone.
- [ ] A Hindi speaker does the same for `hi`.
- [ ] Both check that the **rupee amounts land in the right place** in the
      interpolated sentences — the tests check the number appears, not that the
      sentence reads naturally around it.
- [ ] Check the register: this should sound like a neighbourhood business
      talking, not like a bank or a government form.
- [ ] Then delete the `unreviewed()` note for that language in `i18n.js`.

## Adding to it

```js
// src/ui/i18n.js
const EN = { 'job.newThing': 'What the person sees' };   // source of truth
const HI = { 'job.newThing': '…' };
const TE = { 'job.newThing': '…' };
```

`i18n.missing('te')` lists every key that language still lacks, so the gap is
countable rather than a feeling. If the new string is one somebody could lose
money or a day by misreading, add its key to `CRITICAL` in
`core/selftests.i18n.js` so the build refuses to ship it untranslated.
